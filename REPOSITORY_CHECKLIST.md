# Repository release checklist

Before the manuscript is submitted or a new repository release is created:

- [ ] `verification_IJIO_v6.py` is the same version used for the manuscript's reported calculations.
- [ ] `python verification_IJIO_v6.py` completes without error.
- [ ] `verification_output_v6.txt` has been regenerated from the committed script.
- [ ] `requirements.txt` reflects the versions used for the reference run.
- [ ] The manuscript's Data Availability statement points to this repository.
- [ ] README manuscript version matches the submitted manuscript version.
- [ ] `CITATION.cff` version and release date are current.
- [ ] No temporary files, credentials, private data, or unpublished confidential materials are committed.
- [ ] Create a GitHub release/tag matching the manuscript version (recommended: `v6-submission`).
- [ ] After acceptance, update the README and citation metadata with the DOI and final bibliographic information.
